Se realizó una petición POST a la ruta:

http://localhost:3000/registro

Enviando el siguiente JSON:

{
  "nombre": "Maria",
  "mensaje": "Hola comunidad"
}

El servidor recibe los datos enviados mediante req.body y responde con un objeto JSON que confirma la recepción de la información:

{
  "estado": "Datos recibidos",
  "nombre": "Maria",
  "mensaje": "Hola comunidad"
}
